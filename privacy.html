Delamain privacy policy

Delamain is a personal assistant used only by its owner, on their own laptop.

What it accesses

With the owner's permission, Delamain reads events in the owner's Google Calendar and adds events the owner asks for. It can remove only events it added itself.

How the data is used

  • Calendar data is fetched only when the owner asks a question about their calendar, and is used only to answer that question.
  • The text of the question and the relevant events is processed by an AI model to produce the spoken answer.
  • The Google sign-in token is stored only on the owner's laptop, readable only by the owner's user account.
  • Calendar data is not sold, shared with anyone else, or used for advertising.

Delamain's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/connections.
